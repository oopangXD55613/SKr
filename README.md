# ระบบจองสถานที่ โรงเรียนสกลราชวิทยานุกุล (Sakonraj Booking System)

ระบบ Single Page Application (SPA) สำหรับบริหารจัดการและจองสถานที่ภายในโรงเรียนสกลราชวิทยานุกุล พัฒนาด้วย **React**, **TypeScript**, และ **Tailwind CSS** ภายใต้ธีมสี **แดง-ขาว** ประจำสถานศึกษา พร้อมลายน้ำสัญลักษณ์โรงเรียน (School Watermark)

## 🚀 ฟีเจอร์หลัก (Core Features & UI Implementation)

### 1. ระบบ Dual Login (สลับบทบาท ครู / แอดมิน)
- หน้าล็อกอินแบบรวมศูนย์ มีปุ่มสลับบทบาทระหว่าง **"ครูผู้สอน (Teacher)"** และ **"ผู้ดูแลระบบ (Admin)"**
- มีปุ่ม Quick Select เลือกทดสอบได้ทันที:
  - **ครูศิริพร ใจดี**: มีแจ้งเตือนการไม่อนุมัติและอนุมัติรอแสดงผล
  - **ครูธนากร กิจการ**: มีรายการคำขอที่เวลาชนกับครูท่านอื่น
  - **นายวิโรจน์ อาคารชัย (แอดมิน)**: สำหรับจัดการคำขอและแก้ปัญหาการจองทับซ้อน

### 2. Teacher Dashboard & Quick Booking
- แสดงปฏิทินรายเดือน (กันยายน 2569) มองเห็นสถานะการจองของทุกคนแบบเรียลไทม์
  - 🟢 **อนุมัติแล้ว (Approved)**
  - 🟡 **รออนุมัติ (Pending)**
  - 🔴 **ไม่อนุมัติ (Rejected)**
- ปุ่ม **"จองสถานที่ด่วน"** เปิด Modal ให้ระบุ:
  - สถานที่ (พร้อมแสดงความจุและอาคาร)
  - วันที่และช่วงเวลา (เริ่ม - จบ)
  - วัตถุประสงค์และจำนวนผู้เข้าร่วม
  - อุปกรณ์เสริม (จอ LED, ไมโครโฟนไร้สาย ฯลฯ)
  - มีระบบ Real-time Conflict Warning แจ้งเตือนครูล่วงหน้าหากเลือกเวลาที่ชนกับผู้อื่น

### 3. Teacher Notification System (แจ้งเตือนผลการจองเมื่อล็อกอิน)
- เมื่อครูล็อกอินเข้าสู่ระบบ หากมีคำขอที่ได้รับการอัปเดตผล (อนุมัติ / ไม่อนุมัติ) Modal แจ้งเตือนจะเด้งขึ้นมาโดยอัตโนมัติ
- กรณี **"ไม่อนุมัติ (Rejected)"**:
  - แสดง **"เหตุผลที่ถูกปฏิเสธ"** ชัดเจนในกรอบสีแดง
  - แสดง **"ชื่อแอดมินผู้ตอบกลับ"** และตำแหน่ง/หน่วยงานที่รับผิดชอบ
  - มีปุ่ม "รับทราบทั้งหมด" เพื่อเคลียร์สถานะ

### 4. Admin Dashboard & Conflict Resolution (จัดการการจองทับซ้อน)
- บนปฏิทินของแอดมิน จะมีจุดสีเหลืองเตือนในวันที่มีรายการรออนุมัติ (Pending) และป้ายกะพริบสีแดง `⚠️ ชนกัน` ในวันที่มีการจองทับซ้อน
- เมื่อคลิกดูวันที่ 12 ก.ย. 2569 จะเปิด **Scrollable Modal** แสดงรายการคำขอ
- **กล่อง Conflict Alert สีแดง**:
  - ระบบตรวจจับอัตโนมัติเมื่อพบการจองสถานที่เดียวกันและช่วงเวลาคาบเกี่ยวกัน
  - นำรายการที่ชนกันมาวางเทียบกัน (เช่น คำขอของครูธนากร vs ครูประสิทธิ์)
  - แอดมินสามารถกด **"อนุมัติคำขอนี้"** หรือ **"ไม่อนุมัติ"**
- **บังคับกรอกเหตุผลการปฏิเสธ**:
  - เมื่อแอดมินกด "ไม่อนุมัติ" ระบบจะเปิดหน้าต่างบังคับพิมพ์เหตุผลใน `<textarea>`
  - ปุ่มยืนยันจะ **Disabled** ไว้ จนกว่าจะพิมพ์เหตุผลอย่างน้อย 5 ตัวอักษร
  - มีปุ่มข้อความสำเร็จรูป (Presets) เพื่อความรวดเร็วในการทดสอบ
